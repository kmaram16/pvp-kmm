# PvP KMM 🔫

Shooter en primera persona hecho por **KMM** en Unity.

- ✈️ Saltas de un avión con paracaídas
- 🥊 Duelo por equipos (1v1 → 4v4 con amigos) y 👑 Battle Royale con tormenta
- 📦 Suministros que caen del cielo
- 🤖 Bots para jugar solo

## Descargar (Windows)
Ve a **[Releases](https://github.com/kmaram16/pvp-kmm/releases/latest)**, descarga `PvP-KMM-Windows.zip`, descomprímelo y abre **PvP KMM.exe**.

Windows puede decir "aplicación desconocida": pulsa **Más información → Ejecutar de todas formas**.

Controles: WASD moverse · ratón mirar · clic disparar · clic dcho apuntar · E coger · R recargar · Espacio saltar / saltar del avión · Tab marcador · Esc pausa.
